# desafio-colaborativo-git
🧮 Calculadora em Python

Projeto desenvolvido em sala de aula com o objetivo de praticar os conceitos básicos de Python, Git e GitHub, utilizando um fluxo de trabalho colaborativo em equipe.

 Sobre o projeto

Esta é uma calculadora simples desenvolvida em Python, capaz de realizar as quatro operações matemáticas básicas:

➕ Adição

➖ Subtração

✖️ Multiplicação

➗ Divisão

O projeto foi desenvolvido por um grupo de 4 pessoas durante uma atividade em sala de aula, com foco no aprendizado e na prática do controle de versões utilizando Git.

🎯 Objetivos

O principal objetivo do projeto é aprender, na prática, como utilizar o Git para controlar versões de um projeto e como colaborar utilizando o GitHub.

Durante o desenvolvimento, foram praticados conceitos como:

Criação e clonagem de repositórios

Criação de branches

Alterações e commits

Push e Pull

Merge de branches

Resolução de conflitos

Trabalho colaborativo com GitHub

Além disso, o projeto permite reforçar conceitos básicos de programação em Python, como:

Variáveis

Funções

Condicionais

Entrada e saída de dados

Operadores matemáticos

🚀 Como executar
1. Clone o repositório
git clone URL_DO_REPOSITORIO

2. Entre na pasta do projeto
cd calculadora-python

3. Execute a calculadora
python calculadora.py


Dependendo do sistema operacional, pode ser necessário utilizar:

python3 calculadora.py

🌿 Fluxo de trabalho com Git

Durante o projeto, cada integrante pode trabalhar em uma branch própria para evitar alterações diretamente na branch principal.

Depois, a branch pode ser enviada para o GitHub e integrada ao projeto principal por meio de um Pull Request.

📚 Aprendizados

Com este projeto, buscamos compreender como o Git pode ser utilizado para organizar o desenvolvimento de software em equipe.

A atividade também permitiu entender a importância de:

Manter um histórico das alterações;

Criar branches para diferentes funcionalidades;

Fazer commits organizados;

Trabalhar simultaneamente em um mesmo projeto;

Utilizar o GitHub para compartilhar o código;

Resolver conflitos quando diferentes alterações entram em conflito.
